かぎばこ プライバシーポリシー

2026年10月1日

かぎばこ（以下「このアプリ」）は、個人が自分のパスワードを管理するための道具です。 Android アプリと、このウェブページの2つがあり、どちらも同じ扱いをします。

1. 作者に送られる情報はありません

このアプリは、作者が運営するサーバーを使いません。マスターパスワード、保存した ID・パスワード・メモ、 端末の情報、使い方の記録（アクセス解析）は、作者を含むほかの誰にも送られません。 広告や解析のための仕組みも入っていません。

2. 暗号化はお使いの端末の中で行います

保存する内容は、お使いの端末の中で、マスターパスワードから作った鍵（PBKDF2-HMAC-SHA256）と AES-256-GCM によって暗号化されます。 マスターパスワードはどこにも保存されません。作者はこれを知る方法がなく、忘れた場合に復元することもできません。

3. Google ドライブについて

  • 暗号化したファイル（kagibako-vault.json）を、利用者ご自身の Google ドライブに置きます。中身は暗号化されたままで、Google にも作者にも読めません。
  • Google ドライブへのアクセスには、権限 https://www.googleapis.com/auth/drive.file だけを使います。 これは「このアプリが作った、または利用者が選んだファイル」だけを扱える権限で、ドライブにあるほかのファイルを見ることはできません。
  • Google から受け取る情報は、このファイルを読み書きするためのアクセストークンと、ファイルの番号・更新の記録（版の番号・日時）だけです。
  • Google API から受け取った情報の使用と、ほかのアプリへの転送は、 Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。 受け取った情報を、ほかの目的に使ったり、人に渡したり、売ったりすることはありません。
  • Google へのサインインは Google の画面で行われ、 Google のプライバシーポリシーが適用されます。

4. 端末に残るもの

  • ウェブページ: ブラウザの保存領域（localStorage）に、ファイルの番号・端末を見分けるための番号・暗号の計算に使う公開してよい値（salt と回数）だけを残します。暗号化した中身も平文も残しません。ページを閉じると、復号した内容はすべて消えます。Cookie は使いません。
  • Android アプリ: 電波の届かない場所でも見られるよう、暗号化したままのファイルを端末の中のアプリ専用の場所に残します。端末のバックアップや機種変更のコピーの対象からは外しています。

5. 連携をやめるとき

Google アカウントの「サードパーティ製のアプリとサービス」から、かぎばこの連携を解除できます。 ドライブのファイルは、利用者ご自身が消すまで残ります。

6. このポリシーの変更

内容を変えるときは、このページを書き換え、日付を改めます。

Summary in English

Kagibako is a personal password manager. It has no server and sends nothing to its author. All encryption happens on your device; your master password is never stored or transmitted. It uses only the drive.file scope to store a single encrypted file in your own Google Drive. Kagibako's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
